## Code Example

Create function fib that returns n'th element of Fibonacci sequence (classic programming task).

```javascript
function fibonacci(n) {
  let fib = [0, 1];
  for (i = 2; i <= n; i++) {
    fib[i] = fib[i - 2] + fib[i - 1];

  console.log(fib.pop());
}
```
